## 🚀 Overview
Celemony Melodyne for Windows is a pitch and time editing plugin that loads inside a compatible DAW and gives you access to the individual notes in a recording. Instead of treating audio as a fixed waveform, it separates a performance into editable notes so you can retune a vocal, tighten timing, or fine-tune vibrato and note transitions. Melodyne runs as a VST, AU, or AAX plugin and integrates directly with the timeline through ARA in supported hosts, and it is also available as a standalone application. It ships in tiered editions — Essential, Assistant, Editor, and Studio — so you can start small and grow into more advanced tools. Whether you are polishing lead vocals or refining an instrumental take, Celemony Melodyne 5 brings detailed, musical control to your production workflow.

## ✨ Features
- **Note-based pitch editing** — See and adjust each note in a recording to correct tuning while keeping performances natural.
- **Time and timing control** — Move, stretch, and quantize notes to tighten a groove without artifacts.
- **DNA Direct Note Access** — On supported material, work with individual notes inside chords and polyphonic audio.
- **ARA integration** — Edit audio directly on the DAW timeline in hosts that support ARA, with changes reflected in real time.
- **Tiered editions** — Choose Essential, Assistant, Editor, or Studio to match the depth of control you need.

## 🎯 Getting Started
1. Launch your DAW and open a project containing the vocal or instrument you want to edit.
2. Insert Celemony Melodyne on the track as a plugin, or start an ARA edit if your host supports it.
3. Let Melodyne analyze the audio so it separates the performance into editable notes.
4. Drag notes to correct pitch, adjust timing, or refine transitions until the take sits right.
5. Play back in context and print or bounce the result when you are happy with the edit.
